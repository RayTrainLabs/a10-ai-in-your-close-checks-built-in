# A10 workshop tasks: AI in your close, checks built in

Three rounds, each with its own file. Everything in this pack is **fictional**: Muster Präzisionsteile GmbH, near Stuttgart, and every supplier on the invoices are invented for training. It is safe to paste into any chat window.

**One rule before anything else.** Real company figures go only into the AI tool your company has licensed, with names removed. If you aren't sure whether your company has one, use this pack.

Pick your route at the start of each round:
- **A. Run it:** your company tool, with your own real data, names removed.
- **B. Lite:** any chat window, with the files in this pack.
- **C. Watch:** follow on screen, then run it yourself at your next close.

---

## Round 1: write the commentary, then make it show its working (20 minutes)

**File:** `round1_trial_balance.xlsx`

1. Paste the August and September columns into the chat. The figures are in thousands of euros.
2. Type this, exactly:

   > Write one sentence of variance commentary for the five largest movements. Then list every number you used and its row.

3. Give it no reasons. The file contains none on purpose.

**Checkpoint:** how many reasons in your commentary appear nowhere in what you pasted?

---

## Round 2: extract five invoices, then let the total catch it (25 minutes)

**Files:** `invoice_1.pdf` to `invoice_5.pdf`

1. Give the chat all five invoices.
2. Type this, exactly:

   > Return one row per invoice: supplier, number, date, net, VAT rate, VAT, gross. Do not round. No total row.

3. **You add the total, not the model.** Add up the gross amounts yourself, straight from the invoices, in a spreadsheet.
4. Compare your total with the sum of the rows the model gave you. If they differ, stop reading rows and find the one invoice it misread. One invoice in this pack has a rounding trap in it.

**Checkpoint:** did your two totals agree? If not, which invoice broke them?

---

## Round 3: write the board pack paragraph from your own table (25 minutes)

**File:** `round3_variance_table.xlsx`, both tabs: the variance table, and "Our notes".

1. Paste the finished variance table and the three notes. Do not ask the model to calculate anything.
2. Type this, exactly:

   > Write the board pack paragraph from this table and my notes. Use only its numbers. If unexplained, write NOT EXPLAINED.

3. Run the three checks on what comes back:
   1. **Tie it to a control total.** Add up the figures the paragraph claims and compare them to the table.
   2. **Take one input away.** Delete one note and run it again. Does it say a reason is missing, or does it invent a new one?
   3. **Put it next to last period.** Does anything look plausible on its own but odd over time?

**Checkpoint:** did it write NOT EXPLAINED anywhere? Read that line out.

---

## After the session

At your next month end close, run one AI-drafted variance paragraph through the three checks, and send the first number that didn't tie to the facilitator.
